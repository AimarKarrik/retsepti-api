# Porgrammerimine I grupitöö

## Kirjeldus

Projektiks on API, mis suudab filtreerida ja väljastada erinevaid retsepte, mis oleksid tudengitele taskukohased ning kerged valmistada. Projekt oleks abiks tudengitele, kellel on piiratud eelarve, vähe aega toidu tegemiseks või vähe kogemusi keerukamate toitude valmistamisel. Samuti aitaks projekt neid, kes ei tunne ise palju retsepte või soovivad lihtsalt uusi retsepte avastada ning õppida paremini toitu tegema.Valisime selle projekti, sest meile meeldib ise erinevaid toite valmistada ning soovime innustada ja aidata ka teisi tudengeid toiduvalmistamisega tegelema. Lisaks saab loodavat API-d kasutada Sissejuhatus erialasse õppeaine veebilehe projektis, et võimaldada kasutajatel erinevaid retsepte otsida ja kuvada.

# Kuidas jooksutada

<code>flask --app program run</code>
